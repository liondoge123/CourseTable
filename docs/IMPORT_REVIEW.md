# 课程导入预览与校对

## 页面布局

图片、PDF、Excel/CSV、ICS 和教务结果统一进入 `UnifiedImportReview`，备份恢复使用独立确认面板。

手机从上到下依次为返回/标题/更多、问题摘要、问题筛选、按星期分组的可滚动校对清单、目标课表与追加/覆盖选项、固定主按钮。页面复用 LiquidTheme 的字号、颜色、圆角和交互组件。

清单始终展示全部候选记录，不按周次过滤，也不合并同名课程或重叠时间记录。有效记录按周一至周日分组，组内按开始节次、持续节数和课程名排序；无法定位星期或节次的记录置于最前面的“待修正”分组。每张卡片显示课程名、星期、节次、完整周次范围、单双周、教师、地点和校验状态，整张卡片均可进入校对。

校对面板复用课程编辑字段，隐藏颜色和效果预览。图片/PDF 固定显示对应来源片段，支持多来源、切页、放大与完整原图；键盘出现时缩小来源区。底部固定删除与保存按钮。宽度达到 840dp 时使用左侧预览、右侧 380dp 校对面板。

## 状态与交互

| 状态 | 主操作 | 数据行为 |
| --- | --- | --- |
| 名称或时间无效 | 处理 N 条必修正项 | 不能提交 |
| 仅识别存疑 | 导入 N 条记录 | 最终确认说明剩余建议确认项 |
| 无问题 | 导入 N 条记录 | 最终确认目标课表与方式 |
| 覆盖模式 | 覆盖并导入 | 显示将替换的现有记录数 |
| 编辑中 | 保存校对/保存并校对下一条 | 仅修改草稿，禁用页面导入 |
| 保存失败 | 原页面重试 | 保留草稿，事务回滚 |

问题队列先处理字段错误，再处理识别存疑。保存重算队列；手动点击课程保存后返回原周次与滚动位置。删除保留一步撤销。离开未保存字段时可保存或放弃；退出已修改草稿、重新识别时确认放弃。新增课程也进入同一草稿。

## 数据与生命周期

- `CandidateCourse.draftId` 是编辑和队列的稳定标识；来源区域、原始文本及分散的上课记录保留在草稿中。
- `fieldErrors` 校验真实字段，`needsReview` 表示识别疑问；确认不能覆盖字段校验结果。
- `ImportFlowState` 用 ViewModel 保留来源文件、候选记录及导入状态；界面周次、过滤、选中记录和编辑字段使用可保存状态。没有新增持久草稿或进程终止恢复功能。
- 所有课程来源经 `CourseRepository.importCourses` 提交；覆盖删除和写入共用 Room 事务。成功回到课表，失败保留预览。备份恢复仍创建独立课表。
- 编辑器支持完整节次数量，避免原有的四节上限截短导入记录。液态底部面板增加可选的关闭前检查，用于保护未保存字段。

## 验证

- JVM：周次与单双周过滤、分散范围、问题优先级、重叠分组不丢记录，以及现有导入解析测试。
- Android：星期分组、问题筛选、建议确认、连续校对、五节课程、未保存编辑保护、删除撤销、来源对照、重新识别提示、图片入口、CSV/ICS 实际导入、失败重试与事务回滚。
- 截图：浅色/深色清单、校对、确认、真实原图与键盘、320dp/130% 字号及宽屏双栏。验证图片保存在 `.artifacts/import-review/`。
- 本次只构建并安装模拟器测试产物，不修改发布版本，也不交付发布 APK。

2026-09-16 回归结果：55 个 JVM 测试、19 个 Android 测试全部通过；另外通过 320dp/130% 字号的两项界面测试和宽屏双栏测试。完整 Android 输出见 `.artifacts/import-review/android-test-results.txt`。
