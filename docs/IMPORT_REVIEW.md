# 课程导入预览与校对

## 页面布局

图片、PDF、Excel/CSV、ICS 和教务结果统一进入 `UnifiedImportReview`，备份恢复使用独立确认面板。

手机从上到下依次为返回/来源标题/更多、带数量的筛选标签与“开始校对”、按星期分组的可滚动课程清单、目标课表与追加/覆盖选项、固定主按钮。数量为零的分类隐藏；当前筛选分类清空后自动回到“全部”。页面复用 LiquidTheme 的字号、颜色、圆角和交互组件。

完整候选记录保留在草稿中，筛选只改变当前显示；不按周次过滤，也不合并同名课程或重叠时间记录。有效记录按周一至周日分组，组内按开始节次、持续节数和课程名排序；无法定位星期或节次的记录置于最前面的“待修正”分组。每张卡片显示课程名、星期、节次、完整周次范围、单双周、教师、地点和校验状态，整张卡片均可进入校对。

校对抽屉复用课程编辑字段，隐藏颜色和效果预览。图片/PDF 固定显示对应来源片段，支持多来源切换；片段放大与完整原图使用同一液态玻璃抽屉，保留缩放、拖动和原图翻页。键盘出现时缩小来源区。宽度达到 840dp 时使用左侧预览、右侧 380dp 校对面板。

“更多”使用锚定下拉菜单。添加课程在菜单退出后打开独立编辑抽屉；查看原图、重新识别确认和识别范围使用统一的玻璃抽屉。调整识别范围时，导入确认页保持在抽屉后方，取消后返回同一草稿。

## 状态与交互

| 状态 | 主操作 | 数据行为 |
| --- | --- | --- |
| 名称或时间无效 | 处理 N 条必修正项 | 不能提交 |
| 仅识别存疑 | 导入 N 条记录 | 最终确认说明剩余建议确认项 |
| 无问题 | 导入 N 条记录 | 最终确认目标课表与方式 |
| 覆盖模式 | 覆盖并导入 | 显示将替换的现有记录数 |
| 编辑中 | 保存校对/保存并校对下一条 | 仅修改草稿，禁用页面导入 |
| 保存失败 | 原页面重试 | 保留草稿，事务回滚 |

问题队列先处理字段错误，再处理识别存疑。保存重算队列；手动点击课程保存后返回原周次与滚动位置。删除保留一步撤销。离开未保存字段时可保存或放弃；退出已修改草稿、重新识别时确认放弃。新增课程也进入同一草稿。

## 数据与生命周期

- `CandidateCourse.draftId` 是编辑和队列的稳定标识；来源区域、原始文本及分散的上课记录保留在草稿中。
- `fieldErrors` 校验真实字段，`needsReview` 表示识别疑问；确认不能覆盖字段校验结果。
- `ImportFlowState` 用 ViewModel 保留来源文件、候选记录及导入状态；界面周次、过滤、选中记录和编辑字段使用可保存状态。没有新增持久草稿或进程终止恢复功能。
- 所有课程来源经 `CourseRepository.importCourses` 提交；覆盖删除和写入共用 Room 事务。成功回到课表，失败保留预览。备份恢复仍创建独立课表。
- 编辑器支持完整节次数量，避免原有的四节上限截短导入记录。液态底部面板增加可选的关闭前检查，用于保护未保存字段。

## 验证

- JVM：周次与单双周过滤、分散范围、问题优先级、重叠分组不丢记录，以及现有导入解析测试。
- Android：星期分组、问题筛选、建议确认、连续校对、五节课程、未保存编辑保护、删除撤销、来源对照、重新识别提示、图片入口、CSV/ICS 实际导入、失败重试与事务回滚。
- 界面：菜单退出后再打开编辑抽屉、原图/片段抽屉、选区抽屉的背景层级、筛选数量归零后的回退，以及窄屏标签换行。
- 截图：浅色/深色清单、校对、确认、原图与键盘、320dp 和宽屏双栏。本轮新增的临时截图与测试输出保存在忽略的构建或 `.artifacts/` 目录；仓库里已有的历史验证截图保持原状。

## 参考

参考 [Dawn Course](https://github.com/HF-CYGG/Dawn-Course) 的功能划分、[Sleepy](https://github.com/lingion/sleepy) 的多视图思路和 [TimetableView](https://github.com/zfman/TimetableView) 的重叠课程能力。界面与交互在本项目现有 Compose/Liquid 组件上实现，没有引入这些项目的代码或新 UI 框架。
