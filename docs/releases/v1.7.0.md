# CourseTable v1.7.0

## 新增

- 新增时间方案：保存多套节次时间与每节课时长，支持新建、重命名、编辑、删除和选用。
- 设置页的“节次时间”统一为方案列表与编辑详情两层窗口；方案跨课表共用，选用只影响当前课表。

## 界面与交互

- 更新桌面图标，使用蓝色渐变、统一的长短课程块，并提供独立的单色主题图标。
- 操作按钮统一为胶囊形；取消、关闭使用无描边的低强调背景，主要按钮跟随主题色。
- 删除、清空、覆盖和放弃修改使用统一的危险操作样式；识别失败的多个按钮各自独立排列。
- 选中标记统一为圆圈内的勾；移除居中弹窗外阴影。

## 修复与优化

- 减少输入法动画期间主界面的重复重组，调整弹窗避让布局并保留底部操作区域。
- 输入法关闭后清除输入框焦点，退出光标和编辑高亮；再次点击可继续编辑。
- 节次时间校验拒绝空节次、时间重叠和跨越午夜的设置，并修正错误提示中的节次编号。

## 安装

- 最低支持 Android 8.0，使用与历史正式版本相同的包名和签名，可覆盖安装。
- ARM64 设备优先安装 `CourseTable-v1.7.0-arm64-v8a-release.apk`；旧款 32 位 ARM 设备使用 `armeabi-v7a`，不确定时使用 `universal`。
- 三种 APK 的 SHA-256 见随发布附带的 `SHA256SUMS.txt`。
- 输入法动画的改善程度仍取决于设备和输入法；本次没有宣称真机帧率测量结果。
