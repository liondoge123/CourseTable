# 多时段选择入口（2026-10-18）

## 交互

- 将独立的“当前编辑”时间摘要行合并到“上课时段”标题右侧，使用“时段 1 / 3”胶囊与向下箭头。按钮提供“切换上课时段”和当前序号、总数的读屏语义，点击区域至少 48 dp。
- 表单只保留一组时间和周次编辑入口。单时段隐藏切换按钮；新增第二个时段后出现，删除回到一个时段时隐藏。
- 添加和删除集中到卡片底部操作行，删除使用危险色并沿用确认流程。
- 选择面板把编号、时间、周次、地点分层呈现，以主题色及勾选标识当前时段；单节课显示一个节次。点选后关闭面板并切换编辑，取消保留当前时段。
- 选项使用惰性列表，初始位置由 `rememberLazyListState(initialFirstVisibleItemIndex = selectedIndex)` 确定。重新打开十二时段用例时，当前第十二个时段直接可见。
- 切换继续保留已填写的地点、时间与周次，教师和地点输入框保持相邻。
