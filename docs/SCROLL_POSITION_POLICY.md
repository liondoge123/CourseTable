# 页面滚动位置范围（2026-10-24）

## 交互规则

- 一级页面来回切换和短暂进入后台后，保留各自的滚动位置。
- 二级页面退出后重新进入，从顶部开始；父页面保持原位置。取消预测性返回不算重新进入，退出动画中的画面也不提前跳到顶部。
- 切换课表时重置课程列表和课表网格的位置，包括页面当时不在组合中，以及切换后又返回原课表的情况。
- 覆盖导入在数据库提交成功后，仅重置受影响课表的课程列表和网格。失败的提交不发送重置，追加导入及普通课程内容更新不主动重置位置。
- 滚动记录与编辑草稿独立处理，不清除页面状态容器、表单字段、未保存时段或当前编辑入口。

## 实现

`ScrollPositionPolicy.kt` 将滚动记录绑定到浏览范围。根页面持续记录课表切换次数；覆盖成功后生成新的 UUID 修订标识，避免另一个进程中的同次序覆盖复用旧标识。保存的位置同时带范围标识，恢复时校验，防止离屏 `SaveableStateHolder` 中的旧位置被错误带回。只使用 `rememberSaveable` 的输入参数不足以校验已经保存的旧条目。

设置与导入的二级页面按每次进入更新滚动范围，应用于课表管理、节次方案列表、关于、权限检查、教务与粘贴导入页面。离开时保留原标识供退出动画使用，新进入时才更换。一级设置和导入入口继续使用原有位置记忆，编辑器的草稿 Saver 也保持独立。
