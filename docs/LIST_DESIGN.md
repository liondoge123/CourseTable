# 全局列表设计

2026-10-18。共享实现位于 `ui/liquid/ListSurfaces.kt`。

## 材质与层级

| 场景 | 共享材质 | 表达方式 |
| --- | --- | --- |
| 页面独立卡片、设置/关于分组 | `Page` | 清晰的主题表面、轻渐变与细边缘，阅读内容保持稳定 |
| 分组内的小控件、表单入口、节次明细 | `Inset` | 薄透明表面，较轻的高光，适应信息密集区域 |
| 弹窗中的选择项、方案和校对记录 | `Glass` | 同一弹窗背景采样、32 dp 磨砂、轻量折射及内缘高光 |

默认材质根据真实浮层上下文选择 `Page` 或 `Glass`，密集内容显式采用 `Inset`。页面列表使用渐变与边缘绘制，浮层列表才使用背景采样；静态能力下使用主题表面回退。

独立项圆角为 18 dp，分组为 20 dp；选择项间距为 8 dp。标准前导图标区域为 32 dp，图标与文字相隔 12 dp。设置和关于分隔线从文字轴线 60 dp 处开始，无图标的致谢明细从 16 dp 内容轴线开始。标题与说明分层，长文本允许换行，尾部操作保留独立空间。

选中态共用主题色浅光晕、细边缘和圆形勾选；错误、删除等危险状态继续使用语义色。颜色不作为唯一状态信号，选择项同时提供单选与选中语义。列表装饰不处理焦点、键盘或手势，事件由原控件负责。

## 应用范围

- 课程管理独立项、课表管理卡片、课程详情信息行。
- 设置分组、主题选择、权限检查、颜色及步进等设置行。
- 导入入口、学校选择及统一导入/备份校对记录、筛选项。
- 关于页操作、信息、致谢及分组标题。
- 上课时段选择、时间与周次入口、节次方案、节次明细与下拉菜单。

课表网格、时间滚轮和周次网格使用各自的交互结构，共享主题语义色与排版。修改设计时优先调整共享组件，新增普通列表项应复用这套材质和布局参数。

## 布局与交互检查

- 长菜单标题为选中标记预留独立列，点击区域至少 48 dp。
- 主题模式采用整行单选语义，点击一次应用并关闭。
- 颜色选项在窄屏中自动换行，长致谢名称为许可证标记保留空间。
- 同组按钮、保存与取消、增删、草稿、导入提交等沿用已有动作逻辑。

## 课程与编辑选择项的紧凑变体

- 普通字号课程项采用 24 dp 前导图标、标题/教师摘要和可同行排列的时间、周次、地点；删除按钮与整条摘要共用高度，点击区域仍为 48 dp。多时段全部保留，可用宽度不足时自然换行。
- 大于 1.3 倍字号时，删除操作回到标题行，摘要使用整宽区域，避免固定操作列挤压长教师或地点文本。
- 时段表单局部采用 12 dp 内边距、8 dp 内容间隔。时间/周次入口最小高度 52 dp；宽度至少 280 dp 且字号不超过 1.3 倍时，标签和值同行显示，窄屏或大字体采用上下布局。
- 时段选择弹窗合并周次与地点为一段摘要，条目最小高度 64 dp，继续使用共享玻璃材质与完整选中语义。
