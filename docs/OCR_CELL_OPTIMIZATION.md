# OCR 单元格复核与重复长图优化（2026-10-18）

后续重复画面预检及课程名确认流程见 [继续优化记录](OCR_PREFLIGHT_OPTIMIZATION.md)。下方保留第一轮对照数据。

## 改动

- 明细表先用 ML Kit 定位，不再逐个复核课程代码、学分、学院等不导入的字段；周表仍保留原有 Tiny 复核路径。
- 表格线依据相邻像素行的亮度差检测，支持白色覆盖后仍存在的浅灰线，并将连续线段归为一个边界。文字行通过局部直方图确定前景阈值。
- 课程名按完整单元格中的文字行运行已有 Tiny 模型，避免单词框切碎名称、漏掉换行尾部。列边界优先采用纵向表格线，回退到表头中点时保留实际可见文字范围。
- 完整行置信度达到 0.92 时可提出带待校对标记的新名称；较低置信度（至少 0.7）的尾行需要 ML Kit 原图或增强图读数一致。原名称包含复核字典外字符时继续保留原名，另列建议。阈值是启发式规则，不是经校准的准确概率。
- 名称发生变化时保存原识别结果，校对页可查看并选择另一结果；名称候选按字段应用，不依赖整段名称恰好对应一个 OCR token。
- 合法的时间值也进行定点复核。整图与裁剪存在分歧时必须标记；两个裁剪视图一致、位置及框宽相符、周次集合不变且不丢弃已有节次区间时可提出时间修正，仍保留整图读数。只有一个不同裁剪读数或涉及周次集合变化时继续保留整图时间。
- 单独的 `17周` / `3节` 属于合法时间，不再被当成非法语法自动扩展为区间。
- 重复表头按表格分段，区域 ID 保持唯一。完整画面只有在哈希筛选及逐像素比对均通过后，才合并完全相同的重复片段；识别区域坐标映射回原长图。只改变一个像素也不会采用该合并路径。
- 候选级去重要求名称、时间、实际周次、教师和地点一致，合并后保留来源和分歧；未补齐的时段、不同教室、不同教师和不同周次继续保留。

本轮没有添加模型、词库样本答案、云端上传或网络服务。测试样本坐标和课程名称仅存在于测试资源，不参与产品识别规则。
