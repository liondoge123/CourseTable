# 一级页面横向切换

课程、导入、设置一级页面支持左右拖动切换底部导航标签，使用 Compose `HorizontalPager`，拖动直接带动页面移动，松手后吸附到目标页或回到原页。底部点击与页面滑动共用同一个 `PagerState`，选中项取当前靠近中央的页面。

- 课表页横向手势继续用于切换周次；从其他页面可右滑回课表。手势用途在根分页完全落定后切换，拖向课表过程中仍可反向拖回。
- 二级页面打开、输入法显示或玻璃浮层存在时暂停根分页手势。底部导航自身的拖动仍由导航控件处理。
- 课程列表项的横向拖动统一交给根分页，左右切页不会打开编辑器或删除课程；点击列表项进入编辑，从编辑页底部红色入口确认删除整门课程。旧侧滑组件与展开状态已移除。
- 相邻预加载页面在分页落定前不激活返回处理与浮层入口，也不暴露无障碍子节点，避免命中屏幕外的标题或控件；每个一级页面独立记录是否打开二级页面，避免其他页的挂载/销毁回调改写当前页面状态。
- 页面切换只改变导航状态，不新增键盘清焦点逻辑，不修改课表周次切换、课程保存或导入数据规则。

实现位于 `MainActivity.kt` 和 `ui/RootNavigationPager.kt`。行为回归位于 `RootNavigationPagerTest` 与 `RootNavigationTest`，课程列表点击与编辑页删除由 `CourseManageListTest` 覆盖。
