# 一级页面横向切换

课程、导入、设置一级页面支持左右拖动切换底部导航标签。`RootNavigationHost` 用 `SeekableTransitionState` 统一驱动 Dock 点击和手势切页，两者均为整屏横向平移，不做淡入淡出。手指拖动保持 1:1 跟随；点击与松手吸附使用同一组无回弹弹簧参数，松手速度会接入后续运动，时长随距离和速度自然变化。课表页自身横向手势仍用于切换周次。

点击只组合来源和目标页，不滚动 Pager、交换页序、等待准备帧或在结束时恢复索引。`AnimatedContent` 以 `RootDestination` 为内容 key，配合同一 `SaveableStateHolder` 保存各页状态；连续点击交给过渡系统从当前画面重定向，点击返回仍在退出的页面也不会重复注册保存 key。点击动画不被页面按下或轻微反拖取消，避免停在半屏。拖动中的 Dock 请求直接继续当前过渡或重定向到新目标，不再先吸附到中间页。实现位于 `ui/RootNavigationState.kt`。本次未修改液态镜片驱动、拖动、回弹或外观。

- 课表页横向手势继续用于切换周次；从其他页面可右滑回课表。手势用途在根分页完全落定后切换，拖向课表过程中仍可反向拖回。

## 当前方案：速度连续、减速更舒缓（2026-10-23，b240）

旧实现把释放速度仅用于选择目标页，然后丢弃速度并用固定 180 ms 的 FastOutSlowIn 曲线继续。这会使手势结束时运动重新从零速度起步，再迅速完成。当前改用 `RootPageMotion` 的临界阻尼弹簧：刚度 400、阻尼比 1、位置阈值 0.001。参数由本项目调校，未将其声称为 iOS 27 的原生分页参数。

参考 [Apple《Animate with springs》](https://developer.apple.com/videos/play/wwdc2023/10158/) 关于手势与动画保持位置/速度连续、无回弹平滑弹簧的原则，以及 [Flutter PageScrollPhysics](https://github.com/flutter/flutter/blob/master/packages/flutter/lib/src/widgets/page_view.dart) 将当前速度交给分页弹簧吸附的实现。Flutter 的 [Cupertino 路由](https://github.com/flutter/flutter/blob/master/packages/flutter/lib/src/cupertino/route.dart) 也区分拖动中的线性映射和松手后的自动运动；本项目保留这个区分，不照搬导航栈的层叠视差。

直接拖动仍是 1:1 位移；松手后以当前进度和规范化释放速度创建 `TargetBasedAnimation`。快甩与慢拖有不同的轨迹，低速松手不再在 180 ms 内全部结束。无初速整屏运动在 180 ms 约到 87%、350 ms 约到 99%，接着自然收尾。临界阻尼和边界速度约束避免翻过终点再反弹，也避免把大速度简单裁剪成边缘停顿。速度方向按当前来源/目标换算；反向松手仍可先制动再回到原页。

Dock 点击使用同一 `SpringSpec`；正在吸附时点击当前来源或目标，继承当前吸附速度继续或转向。根页面状态仍以 RootDestination 为保存 key，快速点击、半屏按住保护、课表周次隔离和液态镜片实现保持原样。系统动画倍率作用于时间和速度换算，关闭动画时直接对齐。
