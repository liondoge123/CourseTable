# 外观与课表壁纸

外观入口位于「设置 → 外观」。自动、浅色、深色模式及五种颜色保持兼容；「主题色彩」更名为「强调色」，用于操作和选中状态，默认背景改为中性层次。

「课表壁纸」由所有课表共用，仅用于课表主页。图片固定在页面背景，课程网格滚动和翻周不会移动壁纸。设置、课程管理、导入页面继续使用普通背景。

## 玻璃效果

「设置 → 外观 → 玻璃效果」提供「标准玻璃」与「通透玻璃」两种预设，默认标准玻璃。标准玻璃在实时背景采样上叠加 24% 的中性底色；通透玻璃去掉额外底色，保留原有模糊、折射、高光及选中态。两种效果都适配浅色和深色主题。

顶栏胶囊、底部 Dock、加号的连接底座和分离后的按钮共用同一套底色规则，选择后即时生效，全局保存至 DataStore 的 `glass_effect`，跨课表与重启保留；缺失或未知值回退标准玻璃。系统不支持背景模糊时，两种预设都保留可辨认的静态底色。

课表底板不透明度独立调整；状态栏仍透出壁纸并保留渐变模糊。密集编辑器、弹窗和菜单继续使用各自的可读性材质。

弹层采用全区域均匀的半透明底色和背景模糊，静态兼容模式也使用均匀底色。边缘仅保留细微高光与阴影，不叠加宽幅浓色遮罩或纵向底色渐变，避免四周不透明、中间透底。普通玻璃列表卡片使用均匀底色，选中态保留强调色提示。

弹层背景先在完整窗口记录层上做 40dp 模糊，使用 Clamp 重复窗口边界像素，再按弹层形状取样和裁切。弹层及内部玻璃列表不再对局部裁片重复模糊，避免左侧和底部混入窗口外透明像素，漏出下层清晰文字。课程详情的信息行直接使用弹层材质，不额外叠加中间卡片底色。`OverlayBlurEdgeTest` 在深浅色主题下用黑白棋盘背景比较四边与中央残留的细节对比度；需要设备执行像素验证。

## 编辑与保存

壁纸页使用固定的简洁顶栏，仅保留返回和标题，移除取消按钮与副标题。返回丢弃未应用的调整；预览仅保留简短的拖动与缩放提示。滑块直接显示已保存的 opacity 值，旧配置无需转换。

- 使用系统图片选择器，旧系统自动回退文件选择，不申请相册读取权限。选择动画图片时使用静态首帧。
- 拖动预览调整位置，双指缩放；缩放范围为铺满尺寸的 1–3 倍。模糊范围 0–24dp，默认 8dp；遮罩范围 0–80%，默认 30%。遮罩颜色随深浅色模式变化。
- 「课表底板不透明度」范围为 0–100%，默认 65%；0% 完全透明，100% 完全不透明。仅调整整个课表网格所在卡片的底色，文字、网格线及课程小卡片保持原有显示；预览实时更新，应用后保存，取消不提交，重置恢复默认值。旧壁纸配置缺少此字段时保持默认外观。
- 「课程卡片不透明度」独立控制课程小卡片背景，范围为 0–100%，默认 100%。调整不降低文字、课程色条、进度和边框的不透明度，也不改变点击区域；与底板不透明度一样支持预览、取消、重置与保存。旧配置缺少 `cardOpacity` 时课程卡片仍不透明。
- 「调整 → 文字清晰度」提供「课表文字：自动 / 深色 / 浅色」及默认开启的「文字清晰增强」。仅作用于日期、星期、节次和上下课时间；课程卡片文字、玻璃控件和应用主题不受此选项影响。旧壁纸默认自动模式和开启增强；草稿、返回、应用及重置沿用壁纸编辑事务。
- 预览复用真实课表网格和课程卡片。课程卡片在壁纸模式下默认使用不透明底色，网格底板默认以 65% 不透明度允许背景透出；卡片文字跟随主题，日期和时间轴使用独立的文字清晰度配置，今天以实色日期标记突出。壁纸延伸至状态栏，状态栏仅保留渐变模糊，不额外叠加主题色遮罩；不支持玻璃模糊的系统直接透出壁纸。底部导航栏保留局部遮罩。
- 更换、调整、重置、移除均属于草稿，只有「应用」才修改已保存配置。取消或返回不提交草稿。文件缺失时回退普通背景，可以重新选图或移除。

## 存储与渲染

`WallpaperConfig` 在 DataStore 的 `timetable_wallpaper` 键中保存图片标识、归一化位置、缩放、模糊、遮罩、课表底板不透明度 `gridOpacity` 和课程卡片不透明度 `cardOpacity`。现有主题键不变，不涉及 Room 迁移，课表 JSON 备份和分享文本不包含壁纸。

文字配置以 `textMode` 和 `textClarity` 保存在同一配置中。自动字色对已解码和模糊的位图可见取景做固定 12×20 点采样，再叠加遮罩和课表底板计算字色；不重新解码，不在滚动或翻周时重复采样。清晰增强以任意黑白壁纸极值为边界，计算日期栏和时间轴所需的最小局部底色强度，以 5:1 为计算目标并留出量化余量；取景采样仅选择字色，不作为最坏背景的假设。现有底板足够清晰时不额外托底，关闭增强则不补底色。今天的实色日期徽标独立按强调色选择可读字色。

图片复制到应用私有 `files/wallpapers/`，限制输入文件为 64 MiB、像素总量为 2 亿，按采样限制最长边不超过 2048 像素，并处理 EXIF 方向。删除相册原图不会影响已保存壁纸。保存失败保留原图；成功替换后才删除旧图；取消时删除草稿，启动时只清理该目录内可识别的遗留壁纸文件，保留当前配置引用的图片。

后台解码、方向校正及 CPU 模糊兼容 Android 26；滤镜在最长边 768 像素的副本上运行，使用预乘透明度避免透明边缘污染。图片缓存上限为 32 MiB；位置和遮罩变化不触发滤镜重算，滚动、翻周及导航动画不重新解码。新的滤镜任务取消过时处理，并在结果准备好前保留同一图片的上一帧。

页面背景插槽同时提供背景采样与内容采样；玻璃控件不采样自身。底部导航仍采样完整页面，壁纸随课表页面一起参与切页和返回动画。

## 回归验证

课表左侧节次与时间、节次时间方案摘要与编辑列表、变更预览及数字/时间滚轮通过 `TextStyle.tabularNumbers()` 启用等宽数字（`tnum`，关闭 `pnum`）。沿用系统字体及原有字号、字重、行高和布局，不替换中文字体，也不改动滚轮取值、输入焦点或键盘行为。

- `WallpaperConfigTest`：序列化、非法值、路径边界、不同图片与窗口比例的铺满和裁切。
- `WallpaperRepositoryTest`：草稿与提交、失败事务、重启及切课表、旧图和遗留文件清理、方向、长图、透明度及滤镜缓存。
- `WallpaperEditorTest`：选图与取消、重置与应用、移除及缺图恢复、拖动和双指缩放、五种强调色、深浅色和大字体。
- `WallpaperNavigationTest`：滚动时背景固定、翻周、页面隔离、取消预测返回及 Activity 重建。
- `WallpaperReadabilityTest`：深浅主题、五种强调色、三种字色、遮罩和底板透明度组合下的对比度、关闭增强及今天日期徽标。
- `WallpaperAxisRenderingTest`：可见取景采样；黑、白和棋盘格壁纸在深浅主题、底板透明度为零时的实际文字样式和背景像素对比度，及课程点击不受保护层拦截。

本地构建使用 `testDebugUnitTest` 和 `lintPreview`，设备侧使用 Android instrumentation 测试。测试截图只能写入本次会话的 `/data/local/tmp/coursetable-testing/<session>/`，拉取后按明确文件清单清理。模拟器验证不能代替真机玻璃渲染及手势验证。
