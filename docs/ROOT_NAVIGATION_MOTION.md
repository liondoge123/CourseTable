# 根页面切换与连续点击（2026-10-26）

## 交互目标

保留液态 Dock 的按压、镜片形变与释放反馈。正文使用不回弹的横向整页滑动，点击和手势采用相同的物理方向。切换过程中可随时点击其他标签；页面从当前可见位置接续，反向请求先制动再返回，不重播一段从静止开始的动画。

## 实现与取舍

`RootPageTransition` 维护已请求页面的锚点及一条以屏幕宽度为单位的位移。`RootNavigationHost` 在放置阶段读取这条位移，所有页面以相同速度移动并保持边缘相接；不再由 `SeekableTransitionState` / `AnimatedContent` 分别推进旧初值和新目标，避免连续改目标时多段位移速度叠加。

反向点击复用仍挂载的目标页面。第三个目标尚未挂载时，从现有页面带的边缘进入；因此极快连点可以经过之前已请求、仍在运动中的页面。不会为了跨标签点击而创建未请求的中间页面。最多保留四个已请求页面，落定后只保留最终页面，并在同一次状态更新中归零锚点和位移；目标页面的 `SaveableStateProvider` 保持相同的组合键。

弹簧阻尼比仍为 1，基础刚度为 400。超过一屏的剩余距离按距离平方降低刚度，使静止出发时的峰值速度保持约 7.36 屏宽/秒，不因页数成倍增加。点击中断继承上一段实际屏幕位移速度；手势松手继承手指速度，并根据目标距离和页面带边缘的空间约束初速度，避免越界。首帧精确保留起点，避免弹簧求值中的浮点舍入产生微小反向步进。每帧的位置在 `withFrameNanos` 回调内发布，避免先恢复协程再更新状态造成额外的调度交接。

收尾阈值从 0.001 调整为 0.004 屏宽，去掉低速尾段的一部分。单屏从静止出发约 260 ms 已完成超过 96% 的位移，完整弹簧落定小于 450 ms。系统动画倍率继续缩放模拟时间，关闭动画时直接落定。拖动期间仍按最近页面更新 Dock，取消/反向甩动松手时立即选中真正落定的页面。

逐帧位移仅在布局放置阶段读取；主界面和 Dock 选中态不订阅每个移动增量。页面未落定时保留原有的输入和返回层保护，课表自己的周分页手势保持独立。

## 回归与诊断

`RootPageMotionTest` 覆盖距离与峰值速度、反向制动、收尾、手势初速度和边界约束。`RootNavigationPagerTest` 补充第三目标重定向的可见位置、相接边缘、像素不透明性及逐帧位移，以及反向点击的制动轨迹。

`NativeDockRetargetTest` 使用真实液态 Dock、原生手指事件及真实渲染时钟，以 32 / 80 / 160 ms 间隔分别连续点击七次。检查所有请求抵达、实际中断发生、点击交接位置不跳变、页面锚点相接，并通过仅诊断时启用的 `page.motion` 获取对应动画帧的弹簧速度。测试阈值为归一化到 1× 系统倍率后的 11 屏宽/秒；JVM 的连续改目标用例另以 1 ms 间隔检查三种节奏的逐段轨迹低于 10 屏宽/秒。渲染帧节奏另用 `RootNavigationFrameProfileTest` 采样。

早期原生速度断言把不同阶段的数据相减：帧回调中的模型位置、绘制开始前的全局布局坐标、以及预期 VSYNC / 实际回调时间不一定对应同一帧。只点击一次、没有中断的场景也能得到超过理论峰值的“瞬时速度”。这些失败记录保留供诊断，不能作为屏幕实际加速的证据，也不能据此证明帧发布改动解决了物理手机的卡顿。最终将运动轨迹与渲染帧节奏分开验证；模拟器结果不代表物理面板 FPS。

本轮日志保存在忽略目录 `.artifacts/page-motion-20261026/`。设备测试不向共享存储或 `/data/local/tmp` 写截图、录屏、XML；测试记录直接流到电脑。
