# 多时段、统一导入与离线 OCR

## 数据和兼容

Room v5 的 `courses` 保存名称、教师和颜色，`course_sessions` 保存星期、节次、周次和教室。`CourseRecord` 是持久化课程，`CourseWithSessions` 是聚合关系；现有周视图和提醒使用 `Course` 时段展示模型，其中 `id` 为时段 ID，`courseId` 为共享课程 ID。

v4→v5 不自动改写旧记录：每条旧记录转换为一门课程及一个时段，保留原 ID、颜色、教室及离散周次。课程管理只展示课程并提供编辑、删除，归并在导入流程默认完成，不再提供独立的手动合并入口。

课程编辑支持多个时段；名称、教师、颜色影响全部时段，时间、周次、教室影响选中时段。删除最后一个时段同时删除课程。提醒与 ICS 导出按时段工作。

JSON v4 使用 `courseGroups[].sessions[]`，以备份内关系键恢复课程，绝不直接采用外部数据库 ID。继续读取 v1–v3，旧版平铺记录在导入时按相同课程自动归并；v4 已明确的课程关系保持原样。备份逐课表校对，默认新建；最后确认在一个事务内恢复所有课表。

## 导入规则

各来源转为 `ParsedImport`，共享候选校对及 `ScheduleAnalysis`。普通导入默认追加，可循环切换新建或覆盖。覆盖明确说明将删除的时段数，并二次确认。

名称统一全半角和空白，保留实验等后缀；实际周次集合、星期和节次相同才判重复。重复默认跳过，可更新教师和本时段教室，保留颜色。不同时间段默认加入唯一匹配的课程，保留已有颜色；即使存在其他教师的同名课，只要能唯一匹配教师也无需手动选择。只有教师冲突或多个兼容对象时才选择归属或另建。

时段编辑使用共享的表单卡片、Lucide 图标、选择列表和胶囊按钮。多时段通过选择列表切换，时间与周次在同一卡片中修改，添加采用次要胶囊按钮，删除采用危险操作图标及二次确认。教师和“本时段地点”保持相邻，说明文字明确全课程信息与时段信息的作用范围，切换时段保留尚未保存的地点修改。

冲突要求星期相同、实际周次有交集、节次区间重叠，详情展示具体交集，允许仍然导入。排除的无效行不会阻止其他行导入。提交事务中比较最新课表快照，变化后要求重新确认，失败保留草稿。手动编辑使用相同的指纹和冲突规则，并在事务内检查快照。

ICS 按实际日期展开 WEEKLY、INTERVAL、BYDAY、COUNT、UNTIL，应用所有 EXDATE。COUNT 在排除日期前计数。无法匹配作息及不支持的规则保留待修正记录，不默认第 1–2 节。CSV、备份和教务字段错误保留待校对。

## OCR 路径

保留捆绑 ML Kit 中文识别和 PP-OCR Tiny。长截图分块重叠识别；图片保留 EXIF 和选区，按像素限制解码。使用投影评分校正明确的小角度倾斜，表格分析保留原色，存疑区域追加原图放大和对比增强两次尝试。

Tiny 不再按一个阈值覆盖 ML Kit：保留原文、候选、置信度、坐标和疑问原因。不同但合法的时间需确认，英文单词空格保留。无文字框区域通过行投影和表格区域补识别。名称、时间、周次疑问均能对照原图查看和选择候选。

显示预览 JPEG 与识别 PNG 分离，区域重试读取无损识别图。局部重试先展示差异；默认保留人工修改，也可明确选择覆盖。跨页合并使用实际周次集合，保留缺课周和全部来源。缺周次记录必须人工选择，不视作整学期。

PDF 优先文字层，结构缺失时追加 OCR 区域结果。页面串行处理，进度报告读取、识别、解析阶段；可以取消，已启动的 ML Kit 任务完成后再回收其位图。结束时释放识别器、Tiny 会话和缓存。

## 验证与限制

- 本地：单元测试、Android 测试编译、Lint，以及 `python scripts/check-session-migration.py` 的实际迁移 SQL、Room 列和索引、ID、周次、颜色和级联检查。
- 设备：`CourseSessionsTest`、`ImportTransactionTest`、`CourseWeeksMigrationTest`、导入校对测试、`TimetableOcrTest`、`OcrBenchmarkTest`、`EndInputOnOutsideTapTest`、`NativeKeyboardSwitchTest`。
- OCR 基准扩展原图、低对比、轻微倾斜和长截图，结果通过 logcat 流式输出，不在共享存储或用户目录落盘。记录课程召回率、精度、时段数、无效项、存疑项、耗时和抽样 PSS；抽样 PSS 不代表严格峰值。
- 初版实现时未连接 Android 设备。2026-10-15 在 Android 14 模拟器补验：原始 PDF 的文字层和完整导入链路 2 项通过，课程会话、导入事务及旧版本迁移 7 项通过。物理手机上的键盘连续性、图片 OCR 精度和性能基线仍需验证。
- 显著透视和严重模糊照片需调整图片或手动补录；本次没有新增大型检测模型、在线识图或外部 AI JSON 入口。

借鉴来源：[CourseForge 导入代码](https://raw.githubusercontent.com/kevin0521-wjw/courseforge/main/web/js/importer.js)、[fkwakeup 识别及校对流程](https://github.com/leng-cs/fkwakeup)。仅沿用适合本项目的归一化、结构解析和校对方式，保持离线识别。

## 2026-10-15：标签式教务 PDF 实例回归

实际 Android PDFBox 输出已去除个人标题和学号，保存为 `labeled-grid-pdf-tokens.json` 测试输入；原始个人 PDF 不打包进仓库或 APK。修改前，15 个上课时段被错误拆成 45 条记录，跨行的教师姓名、教学班和学分被误当课程。

标签式课程现在先按星期列组织，再以“课程名＋带节次的元数据”确定完整课程块，拼回换行的教师、场地字段。第二页可从前页继承表头并识别纯数字节次；同格的模拟电子技术和大学体育分别提取。创业管理的实际周次为 `[7,13]`，教师姓名中的“单”不再触发单周安排，多教师顺序不影响归并。

原文页脚另有 3 门仅提供上课周次的实践课：保留为待校对记录，星期、节次保持缺失，不能凭空安排；19–20 周超过当前学期设置时明确提示。空白单元格和这些实践课不会触发无意义的整页 OCR。本例完整导入路径经模拟器验证为“文字层直读”，正常时段的全部字段有独立人工标注的单元测试核对。

## 2026-10-15：默认归并与时段编辑规范

移除课程管理中的独立合并操作及对应数据接口。新建和追加导入默认将同名、教师一致或一方未填写的时段归入唯一兼容课程；教师列表顺序不同视为一致。遇到教师冲突或多个兼容对象才需要选择，不影响重复时段默认跳过。平铺旧备份同样走默认归并，显式保存分组的新版备份保持其课程关系。

时段表单采用统一卡片、选择列表、Lucide 图标、次要胶囊添加按钮及危险删除确认。为减少滚动并保留原有输入交接方式，教师和本时段地点相邻，标签明确地点跟随所选时段；时间、周次和时段切换集中在时段卡片。浅色、深色、切换未保存地点、时段增删及管理页无独立合并入口均有界面回归。

最终代码未更改焦点清理、输入控件或键盘可见性逻辑；`EndInputOnOutsideTapTest` 与 `NativeKeyboardSwitchTest` 保留原有实现和断言。最终相邻输入布局在 Android 14 模拟器通过课程编辑键盘连续性检查，原生手指连续切换 6 次，键盘关闭次数为 0。物理手机仍需用户实际验收。
