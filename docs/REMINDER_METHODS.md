# 两种提醒方式（2026-10-27）

## 定位

应用提醒仍是主线和默认值。已有用户保留提醒开关、提前时间和“准时优先”选择，不会被自动切换到系统日历。

系统日历提醒是用户主动选择的兼容功能：适合在 CourseTable 导入、编辑课表，但希望由手机日历负责通知的人。手机日历自身的课表功能已经够用时，无需再启用这条路线。若日历中已有同一份课表，需要由用户确认只保留一份提醒；本应用不会读取、合并或删除其他来源的课表。

入口：设置 → 提醒与权限 → 提醒方式。两种方式共用“课前提醒”总开关和提前时间。

## 应用提醒

- 继续使用已有 AlarmManager 路径，可选“准时优先”。开启提醒后留在当前设置页；缺少精确闹钟权限时提示通过“权限检查”设置。选择此提醒方式后进入权限检查，引导确认通知、横幅、精确闹钟、耗电管理及厂商后台设置。
- “准时优先”使用系统闹钟，界面提示部分手机可能显示闹钟标记，图标是否出现不能作为调度是否生效的判断依据。未开启时维持普通精确请求；无精确权限或权限被拒绝时降级并记录实际调度方式。
- 不把公共 API 检查通过等同于厂商后台完全放行；不承诺所有机型都无需配置。

## 系统日历提醒

- 选择此方式并开启提醒时才请求日历权限，授权前不写入日程。仅保存未启用的方式偏好不会写日历。
- 创建独立的本地日历“课程表提醒（自动同步）”，将当前激活课表本学期的后续课程及提前提醒写入 Calendar Provider。不依赖本应用每日唤醒，不为此方式保留应用的课程闹钟或每日维护闹钟。
- 课程修改、提前时间调整、课表切换、应用启动、日历模式返回前台及相关系统恢复事件会重新同步。提供手动同步和日历测试提醒。
- 同步完成后由手机日历发送通知。需要手机日历已启用、通知与提醒配置正确；CourseTable 无法自动认定另一应用的通知已送达。
- 测试日程在两分钟后开始，提前一分钟提醒；重复测试替换上一条自有测试日程。
- Android 系统使用 READ_CALENDAR / WRITE_CALENDAR 权限。在本次一加系统中，原生“仅允许创建”同时允许读取、修改、删除本应用创建的日程，已实测足以完成同步与清理；无需操作其他应用的日程。

## 切换、关闭与数据边界

- 配置切换与投递共用互斥锁。切换到日历前取消应用课程闹钟；切换回应用或关闭时先清理本应用已同步的日程，完成后才启用下一条路线。
- 已排队的应用提醒广播会在锁内重新检查当前方式，防止切换后仍发出旧方式的通知。测试提醒也按当前方式发送。
- 日历权限被撤销且可能存在已写入日程时，清理不会假装成功。切换/关闭需要恢复权限以移除旧提醒，或者由用户在手机日历中处理；不自动回退到可能产生重复通知的应用路线。
- 日历身份同时限定 ACCOUNT_NAME 为本应用包名、ACCOUNT_TYPE 为 LOCAL、NAME 为固定内部名称且 deleted=0。不会复用用户已删除的日历行。
- 事件使用 `CUSTOM_APP_URI` 中的自有前缀和稳定的课表 ID / 时段 ID / 日期标识。更新、删除使用 Events 集合 URI，并同时限定事件 ID、所属日历 ID 和精确标识；不对带额外 selection 的单事件 URI 发请求。
- 只处理独立日历中有本应用标识的事件。用户手动加入该日历但没有标识的事件也保留；切换或关闭不会删除整本日历。
- 切换能清理待触发的自有事件，不能承诺撤回另一应用已经显示的通知。卸载后已经写入的本地日程也可能保留。

## 同步与恢复

- 同步剩余整个学期，遵循课表的周次、单双周、非连续周、多个时段和跨午夜结束时间。
- 已过提醒时间但课程尚未结束的事件仍可显示，且不插入已过期的提醒，避免同步时立即补发大量历史提醒。
- 使用稳定标识查询现有事件，重复同步不重复插入，改时间或提前量原位更新。
- 分批提交 Calendar Provider 操作，每条事件和它的提醒处于同一批事务。写入前持久化“可能存在自有事件”，中断后重新读取 Provider 恢复，不能因中断丢掉清理责任。
- 同步失败显示异常并可重试；已写入的日历内容在成功同步前仍以旧版本为准。

Android API 依据：[Calendar Provider](https://developer.android.com/identity/providers/calendar-provider)。

## 验证记录

设备：一加 12 / PJD110，Android 16 / API 36，固件 `PJD110_16.0.10.501(CN01)`。使用原生 ADB 手势、真实渲染时钟和系统 Calendar Provider；未运行 Compose 模拟时钟来判断通知时效。

本地验证：249 项单元测试通过，Android 测试源码编译通过，debug lint 无错误。新增测试覆盖整个剩余学期、单双周/非连续周、已过提醒时刻、不同课表、稳定事件身份、多时段、跨午夜和旧设置默认值。
