# 管理页面细节优化（2026-10-18）

## 界面与交互

- 课程列表将名称、教师、时段数量与各时段安排分层显示。教师只显示一次；每个时段分别显示星期、节次、周次和地点，单节课显示“第 9 节”的含义，不重复起止节次。教师与时段数量按完整文本块换行。
- 名称与删除操作共享标题行，其余信息使用完整正文宽度；同组分隔线与正文对齐。行内删除目标为 48 × 48 dp，保留二次点击确认与五秒自动复位。
- 空课程页提供说明卡片与直接添加入口，复用原有新建课程逻辑。
- 课表管理使用独立卡片，长名称和学期信息不再与两个操作图标争夺横向空间。当前课表通过勾选、主题色边框和文字标识共同表达，选择项提供单选及选中语义。
- 重命名和删除位于独立操作行，读屏名称包含目标课表；删除使用危险色，唯一课表仍禁止删除。
- 课表改为按稳定 ID 惰性加载，固定顶栏增加新建入口，长列表末尾也可直接新建。
