# 页面顶部液态玻璃过渡

2026-10-17。使用既有 Backdrop 2.0.1；没有新增渲染库或权限。

## 页面策略

| 页面 | 顶部行为 |
| --- | --- |
| 课程、设置 | 大标题随内容滚动，渐变模糊仅限系统状态栏内 |
| 导入首页 | 标题和入口随内容滚动 |
| 粘贴导入、教务学校选择、课表管理、关于 | 返回栏固定且清晰，滚动内容不透入返回栏 |
| 课表 | 恢复原来的悬浮周次胶囊，星期日期在课表卡片内随课程滚动 |

教务登录 WebView 保留安全视口；导入确认和课程编辑抽屉沿用已有固定编辑框架。主导航仍使用原来的液态玻璃胶囊。

课表顶栏的周次、课表名称和单双周筛选统一使用 `labelLarge`（15sp、20sp 行高、600 字重），选中状态用颜色区分；文字和下拉标记保持一致的行高与居中对齐。

## 渲染与边距

`LiquidScrollablePage` 为每个页面单独记录原始背景与内容，状态栏玻璃和按钮在记录区域之外绘制，避免采样自身。状态栏玻璃使用 18dp 硬件模糊和现有 vibrancy，最后 16dp 在状态栏内部渐隐至透明，模糊层高度只取 `WindowInsets.statusBars`，不包括安全区缺口或应用顶栏高度。状态栏图标由系统在最上层绘制，继续按主题使用深浅色图标。

普通固定顶栏使用与页面一致的原始背景遮住滚动内容，不应用大面积模糊。课表开启 `floatingTopBar`，恢复原来的胶囊内容采样和悬浮效果，移除整条背景遮罩；星期日期与分隔线放回课表卡片内。状态栏的高度、模糊半径、渐隐范围和颜色参数均保持不变。

效果链先模糊、再应用 vibrancy，并保留 36dp 的额外采样缓冲。缓冲区域先填充不透明主题底色，再记录实际页面，避免透明区域透出清晰文字。输出仍裁剪在状态栏内；扩大的是输入采样区域，不是可见模糊范围。

没有缓冲时，Clamp 会重复状态栏采样窗口的首末像素行。文字笔画经过边界时，这一行会变成大片黑影，再突然缩回；一像素笔画的复现检查测得顶部红色通道单帧突变 0.337。扩大并填充采样缓冲后，浅色逐像素连续帧检查的最大突变为 0.00392，深色为 0.00784，边界不再重复运动中的笔画。条纹检查同时防止为了消除黑影而让清晰文字穿透顶部。

安全区使用系统栏与显示缺口的并集。顶部边距放在 `LazyColumn.contentPadding` 或滚动修饰器之后，而不是裁剪滚动视口；初始标题保留原有 16dp 留白。底部导航、显示缺口和 IME 消费分别处理。固定栏高度按实际测量调整，适应大字和横屏。

渐隐层不接收触摸。固定栏的空白处会拦截点击，避免误触下方滚过的课程或按钮；返回和其他子按钮照常响应。Android 12 及以上使用实际内容模糊，旧系统使用渐变底色回退。

## 验证

JVM 回归 134 项通过。Android 14 模拟器回归覆盖视口到达状态栏、内容穿过状态栏区域、课程/设置大标题滚动、固定返回栏、静态材质回退、星期日期固定，以及编辑、粘贴和输入焦点行为。原生键盘测试使用真实时钟和手指事件，连续切换 6 次未检测到键盘关闭；模拟器结果不替代手机输入法验证。

状态栏范围修正后，顶部专项与粘贴流程通过，包含屏幕边缘模糊、状态栏下方清晰、顶栏高度不扩大模糊范围及普通固定顶栏不透出滚动内容的检查。周次栏恢复后的滚动检查使用与主页面相同的 88dp 底部导航留白，验证星期日期随课表移动、周次胶囊保持悬浮。Lint 为 0 错误、53 警告、4 提示。

黑影突变修正后，最终硬件 GPU 环境下顶部 10 项回归通过，包含浅色黑笔画和深色白笔画连续帧检查。证据位于 `.artifacts/status-flicker-20261017/`，包括修正前失败记录、修正后结果和边缘亮度指标。

软件 SwiftShader 模拟器的实际页面冷启动曾发生 ANR，系统堆栈显示 RenderThread 等待 QEMU 的 `glCreateProgram`，主线程等待 HardwareRenderer；对照过程未修改交付方案。切换主机硬件 GPU 后，同一采样缓冲实现的实际页面启动和 10 项回归正常，启动检查没有 ANR 记录。此结果不等同于物理手机验证。对照源文件保存在忽略目录中，最终源码已核对与预览包构建时的实现一致。

构建与临时证据位于忽略的 `.artifacts/top-glass-20261016/`、`.artifacts/status-only-20261017/`、`.artifacts/restore-topbars-20261017/` 和 `app/build/`。界面确认阶段只运行调试版本截图；用户确认后通过项目 preview 脚本生成安装包。设备检查文件使用当前会话专用 `/data/local/tmp/coursetable-testing/` 子目录，验证完成后清理。
