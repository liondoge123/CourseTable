- 课程管理点击列表项进入编辑，左右滑动统一切页；删除整门课程从编辑页表单末尾的红色入口进入并确认。节次时间方案采用整行选用、尾部“···”菜单编辑/删除；上课时段、节次草稿采用低强调灰色垃圾桶。课表卡片的重命名、删除等管理操作保留“···”，唯一课表隐藏删除选项。
- 点击课表课程打开的预览弹窗采用直接的中性灰垃圾桶图标，无常驻红底、描边或删除文字，点击区域至少 48 dp。点击后确认删除当前时段，“编辑”继续作为主要操作；取消确认不修改数据。
- 常态保持现有材质、底色和透明度，不新增描边。课程列表没有隐藏的侧滑操作区或直接删除的无障碍动作，读屏用户也通过点击课程进入编辑，再使用底部删除入口。
